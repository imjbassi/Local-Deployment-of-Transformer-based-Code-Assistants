# Internal provenance note

The repository's historical manuscript predates the current artifact contract.
Its round-number performance values, StarCoder-15B discussion, CPU claim, and
editor-integration wording are not supported by preserved sample-level outputs,
raw timings, environment records, or an implementation in this repository.
Those statements are excluded from the present study and must not be copied into
a result table or used as priors.

The current project asks a different, externally relevant question: whether the
five-model HumanEval ordering published together in Qwen2.5-Coder Table 5 is
preserved under documented local deployment. CodeT5 is retained only as an
optional checkpoint-selection diagnostic; a near-zero result from vanilla
CodeT5 would be framed as task/checkpoint mismatch, not as evidence that the
published five-model ranking failed.
